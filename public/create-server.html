Create a BlockForge Server

Want a world that's yours? Host it yourself — it's free. Run the server on your machine, share your IP, and friends join just like a Minecraft Java server. The official Official SMP is the only server we run.

⬇ Download Server Files ~130 KB · Node.js required · Windows / macOS / Linux

The package contains the same server the game uses, trimmed to just host your world. No game files needed — players connect from the BlockForge client.

How to run it

  1. Extract the zip and open a terminal in that folder. 
    npm install
  2. (Recommended) copy .env.example to .env and set: 
    PUBLIC_WS_URL=ws://YOUR_PUBLIC_IP:4000   # the address friends will type
SERVER_NAME=My BlockForge Server
DIRECTORY_URL=https://blockforge-server.onrender.com/api/servers   # show in Community Servers
UPSTREAM_BACKEND_URL=wss://blockforge-server.onrender.com           # friends/DMs go here
    If you have a domain (e.g. play.myserver.net), use that as the address.
  3. Start the server: 
    node server.js      # or double-click start.sh / start.bat
  4. Let friends reach you: forward port 4000 on your router, or use a free tunnel (playit.gg, cloudflared, ngrok) which gives you a wss:// address automatically.
  5. Friends open BlockForge → Multiplayer → "+ Add Server", type a name and your address: 
    ws://YOUR_PUBLIC_IP:4000     (or play.myserver.net)
    The game pings it and shows live players/MOTD. Direct Connect joins instantly without saving.
    If the game is open over https://, your address must be wss:// — a tunnel provides this (browsers block ws:// on https pages).
