📋 MAKER REQUIREMENTS

1 · File formatPlain-text ES-module .bfmod, max 512KB. Must export const manifest — the page reads id, name, version, description, author and icon from it.
2 · ManifestUnique id (lowercase letters/numbers/dashes). Bump version on every update so players get the ⬆ button in-game.
3 · HooksonLoad(api) setup, onTick(dt, api) per frame, onUnload() cleanup. Use api.registerBlock/Item/Mob (ids ≥ 2000) and api.hud for overlays.
4 · OwnershipOnly the uploader (or staff) can update or delete a mod. Taken ids are protected — pick your own.
5 · Content rulesNo obfuscated code, no credential harvesting, no hate or explicit content. Broken mods auto-disable client-side; repeat offenders lose publishing.
6 · AccountPublishing needs a maker account with a linked Google or GitHub identity. Downloads never need an account.
export const manifest = { id: 'my-cool-mod', name: 'My Cool Mod', version: '1.0', description: 'What it does, in one line.', author: 'YourName', icon: '✨', }; export function onLoad(api) { api.addButton('hello', '👋 Say hi', () => api.chat('Hello!')); } export function onTick(dt, api) { /* per-frame logic */ } export function onUnload(api) { api.removeButton('hello'); }
