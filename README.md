# BlockForge

A browser-based voxel sandbox built with Three.js.

---

## Future Feature: The Shattered Echo Dimension

### Concept & Aesthetic

A reality-bending custom dimension with an unstable, broken engine aesthetic.

**Visuals:** Fragmented, floating terrain fragments suspended in an immovable, starless indigo sky lined with scrolling wireframe vectors.

**Foliage:** Neon-pulsing Static Wood and Translucent Glass Leaves. "Glitch Storms" cause local blocks to temporarily flicker into wireframes.

**Physics & Sound:** Inverted gravity pockets force players onto the undersides of islands. Phase-shifting blocks cycle between solid and gaseous states. Audio layers distorted chiptunes with echoing, reversed cave ambience.

### Gameplay & Materials

- **Null Quartz:** Harvested from island undersides; crafts tools that instantly teleport mined drops directly into the player's inventory.
- **Memory Shards:** Gathered from unstable glitch blocks; crafts a Recall Anchor machine for cross-dimensional teleportation back to a designated base checkpoint.
- **Creatures:**
  - *The Glitched Wanderer* — a tall particle silhouette that attacks only if you break the blocks it stares at.
  - *Matrix Pixies* — small flying cubes that randomly swap the positions of physical world blocks.

### Portal Mechanics & Frame Detection

**The Frame:** A standard vertical 4×5 hollow rectangle built from Compressed Magnetite (crafted via an Iron Block surrounded by redstone/lodestones).

**The Ignition:** Players place a Paradox Core (Redstone Torch + Clock + Quartz Crystal) inside the base of the frame, forcing the engine to validate a paradox.
